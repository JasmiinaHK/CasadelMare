# Casa del Mare - Website

This is a responsive website created as practice for an assignment. The website is designed for both desktop and mobile devices.

## Description

The website includes several pages:
- Home page (index.html)
- Login page (prijava.html)
- Candidates page (kandidati.html)
- Employees page (zaposleni.html)
- Management page (menagement.html)

The design from a Figma prototype was used as a base for creating the website.
